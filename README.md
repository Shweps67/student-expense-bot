# Telegram-бот для учёта расходов студента

Проект по курсу. Бот принимает траты одним сообщением («кофе 150»), считает безопасный дневной лимит и присылает отчёты.

## Данные для анализа

Данные **синтетические** (сгенерированы скриптом `generate_data.py`, seed = 42), имитируют опрос студентов и их траты за сентябрь и октябрь 2026. Суммы в рублях.

### `students.csv` (200 студентов)

| Поле | Описание |
|---|---|
| student_id | идентификатор студента |
| age, course | возраст, курс |
| living_type | общежитие / снимает жильё / с родителями |
| has_job | есть ли подработка (0/1) |
| stipend, parents_support, job_income | источники дохода за месяц |
| monthly_income | общий доход за месяц |
| tracks_expenses | ведёт ли учёт расходов (0/1) |
| spend_last_month | траты за октябрь (сумма из expenses.csv) |
| exceeded_budget | потратил больше дохода (0/1) |
| money_runs_out_day | день месяца, когда заканчиваются деньги (пусто, если хватает) |
| would_use_bot | стал бы пользоваться ботом (0/1) |
| main_difficulty | главная сложность с учётом расходов |

### `expenses.csv` (~24 тыс. трат)

| Поле | Описание |
|---|---|
| expense_id | идентификатор траты |
| student_id | связь с students.csv |
| date | дата траты |
| category | еда, транспорт, жильё, развлечения, учёба, здоровье, одежда, подписки, прочее |
| amount | сумма, руб. |
| comment | короткий комментарий |

### Заложенные закономерности

- Траты выше в начале месяца (приход стипендии и переводов) и снижаются к концу.
- По выходным больше трат на еду, развлечения и одежду.
- Расходы на жильё зависят от типа проживания.
- Студенты, ведущие учёт, реже превышают бюджет.

## Запуск генерации

```bash
pip install numpy pandas
python generate_data.py
```
